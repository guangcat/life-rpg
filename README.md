# 战力面板 · Life RPG

把每天的一个小动作，变成看得见的成长。

- [打开生活 RPG](https://guangcat.github.io/life-rpg/)
- [体验假数据演示](https://guangcat.github.io/life-rpg/?demo=1)

建议在手机浏览器中添加到主屏幕。首次联网打开后可离线使用；仍需定期导出备份。

## 日常使用

打开先进入「今天」，完成主线后立即记录；反馈条上的「撤销」可就地纠错。可选填一句学习产出，给复盘留下线索。

「任务」按晨间、午后、晚间、随时分组。管理里可设置每日、每周指定日期、一次性和暂停；当天完成率只计算当天适用的任务。保留 8 XP 的最低入口，同一任务每天最多记录一次。

新存档以英语、概率论、高数为主线；上课全勤默认暂停，设置有课星期后再启用；作业用「添加作业任务」按需新建一次性任务；408 独立练习默认按需，不计每日完成率。操作系统等已有课程任务照常保留。老存档的任务表不被替换，旧作业、408 独立练习按需显示；管理里可自行调整是否计入目标。周复盘仅在周日出现。

「属性」显示数学、英语、专业、毕业、体力、情报六项成长，以及对应的备考覆盖量。覆盖进度不重复增加经验。热力图可左右滑动和点选日期。

属性页同时展示六轴雷达图，以及累计打卡天数、有效学习天数、本周达标 X/7。有效学习日按完成至少一条数学、英语、专业或课程学习任务计算；只打开计划或只做作息打卡不算有效学习，原连续打卡保持不变。休息日不增加有效学习天数，也不扣经验。

词汇进度支持输入本次实际新增词数，例如 37。它只调整累计覆盖量，不增加 XP；普通背词打卡只增加 XP，不会自动填写词汇量。记多时可撤销本次词数或按 1 词更正。Boss 卡的剩余血量只根据已记录的词汇、真题覆盖比例计算，与 XP 无关。

「今天」的进度、倒计时、待恢复、战报和周回顾可以折叠，展开状态会保留。周回顾汇总本周经验、学习日、覆盖进度和产出；经验反映投入，不能代表考试掌握程度。

## 日切、休息与个性设置

设置中可改名字，以及凌晨 0–6 点的日切。新存档默认为凌晨 4 点；旧存档保留零点日切。修改日切不重排历史记录。若会与已有休息日冲突，本次修改不会保存。

每月可安排两天休息：不加经验、不增加学习日，但可以连接已有连击。当天已有打卡时无需使用；当天的休息可取消。

升级会出现称号卡片；完成音效可关闭。支持键盘操作和系统的减少动态效果设置。

## 存档与恢复

记录以日志为准，属性和每日统计自动重算。旧日志会补上稳定标识，原始数据在首次迁移前保留本机副本。

设置 → 本机备份与恢复可导出或导入 JSON。导入先完整校验，替换前保留一个恢复点；无效文件不会覆盖当前存档。保存失败会持续提示。另一个标签页更新了存档时，旧页面停止写入，刷新后再继续。

若旧经验或每日统计与日志不一致，应用会保留原始存档并阻止自动校准写回，可先导出原始字节核对。多标签冲突时，导出的是本页含未保存记录的副本；也应在另一页面导出已保存副本，再核对恢复，避免遗漏任一侧记录。

浏览器清理、换设备和系统设置仍可能影响本机数据。「保护本机存档」仅申请浏览器持久存储权限，不能代替备份。用户自行保存的历史 JSON 放在 `backup/`，发布不会上传该目录。

## 可选云端备份和提醒

设置 GitHub token 后，可把存档同步到私有仓库 `guangcat/life-rpg-data/backup.json`。令牌只在本机的同步配置中，不包含在导出存档里；只授予该仓库 Contents 权限。关闭同步会停止后续请求，已发出的请求和远端历史不会自动撤销。

首次发现远端已有备份或远端版本发生变化时，应用会提示恢复或明确覆盖，不会自动采用新的 SHA 覆盖它。可从云端恢复；网络、权限、超时和本机配置保存失败都会提示。手机 GitHub 访问和个人令牌仍需在实际设备验证。

电脑端脚本的存在不代表自动任务已配置。2026-10-25 最近核验未确认本机自动拉取；工具说明见 [AI辅助/README.md](AI辅助/README.md)。

设有时间的任务可导出 `.ics`，按频次生成并包含提醒。单向导出不回写；建议使用单独的 Life RPG 日历。

本版新存档默认四级日期为 **2026-12-12**（按本次用户指定）。已有四级日期全部沿用，包括旧版按名称新建的日期；不会自动替换为默认值。Boss 卡的「修改四级日期」会编辑同一条倒计时。四级倒计时和每日所需词数统一使用所配置的学习日；当日按剩余量安排，过期不生成未来配速，也不做历史配速预测。旧存档若仍是 12 月 19 日，需手动核对改期。

## 更新与本地预览

发现新版本会提示；设置中也可检查更新。新版本的核心文件全部下载成功后才能接管，旧页面与旧模块保持同一版本。

本机预览：`node AI辅助/preview.cjs`，然后打开 `http://127.0.0.1:8848/life-rpg/?demo=1`。需要 Node.js 22 或以上版本。

维护脚本、自检、测试和历史预览集中放在 [AI辅助](AI辅助/README.md)；运行源码为 `index.html`、`app.css`、`app.mjs`、`modules/` 和 `sw.js`，无需构建工具或运行时依赖。
