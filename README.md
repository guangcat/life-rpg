# 战力面板 Life RPG

把每天的固定动作换成经验值。手机端 PWA:加到主屏即可离线使用。

线上地址:https://guangcat.github.io/life-rpg/

## 设计上的四条硬规则

1. **属性从成绩单长出来,不是通用四维。** 数学 / 英语 / 专业 / 毕业 / 体力 / 情报。
2. **经验绑在真事上。** "要考纲 / 往年题"给情报 +35,因为免听课最大的风险是不知道考什么。
3. **最小入口 8 分,不是 40 分。** "打开计划看一眼"存在的唯一目的是在不想学的那天保住连击。
4. **所有动作 ≤40 分钟。** 入口必须是一个动作,而不是一个判据。

## 三个页面

- **属性** —— 等级、经验条、六个属性、**热力图**(近 16 周,每格一天,按当天 XP 分五档)。
  热力图下面那行显示「共打卡 N 天 · 最长连续 N 天」。只看不改。
- **任务** —— 打卡的地方。点一下记一次;右上「+ 新建」加自己的任务;
  「管理」进编辑模式,可以改任意一条,也可以删。
  **当天做完的会变暗,并自动沉到列表最下面**,组内保持原顺序(不会乱跳)。
- **今天** —— 今天的时间线、今日结算战报、日历导出、备份。

分页的理由:原来所有东西挤在一屏里往下滚,想看属性要先划过任务列表。
现在一页只做一件事。

## 日历导出

任务里填了「时间」的,会导出成**每天重复**的日程(`.ics`)。

- 「分享到日历」走 iOS 分享面板;「导出 .ics」存到「文件」App,点它系统会问是否添加到日历。
- 每条任务的 UID 是固定的(`liferpg-<任务id>@life-rpg`),
  所以改了任务重新导入时,**多数日历会按 UID 覆盖而不是新增一条**。
- 这是**单向**的:App 是源头,日历只是收件箱。在日历里改了什么不会回到 App。

如果导入后发现重复了,说明你的日历不按 UID 去重。办法是导入时选一个专门的
「life-rpg」日历,以后要重来就把那个日历整个删掉再导一次。

## 本地改完怎么重新发布

```powershell
powershell -ExecutionPolicy Bypass -File _deploy.ps1
```

改完 `index.html` 后跑一次这个脚本,线上就更新了。手机上强制刷新一次即可。

如果改了 `sw.js` 的缓存列表,**记得同时把 `CACHE` 版本号加一**,否则手机会继续用旧缓存。

## 自检

```powershell
node _selftest.js
```

改了 `index.html` 的脚本后跑一次,会验证语法、等级曲线、连击、战报、持久化。

## 数据

数据存在手机浏览器的 localStorage 里,不上传任何服务器。

> **必须"添加到主屏"。** iOS 的 Safari 对普通网页标签有 7 天不访问就清除本地存储的策略,
> 而添加到主屏的独立应用不受这条限制。另外每周导出一次 json 备份,存到 D 盘。
