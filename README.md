# 战力面板 Life RPG

把每天的固定动作换成经验值。手机端 PWA:加到主屏即可离线使用。

线上地址:https://guangcat.github.io/life-rpg/

## 设计上的四条硬规则

1. **属性从成绩单长出来,不是通用四维。** 数学 / 英语 / 专业 / 毕业 / 体力 / 情报。
2. **经验绑在真事上。** "要考纲 / 往年题"给情报 +35,因为免听课最大的风险是不知道考什么。
3. **最小入口 8 分,不是 40 分。** "打开计划看一眼"存在的唯一目的是在不想学的那天保住连击。
4. **所有动作 ≤40 分钟。** 入口必须是一个动作,而不是一个判据。

## 四个页面

- **属性** —— 等级、经验条、六个属性、**热力图**(近 16 周,每格一天,按当天 XP 分五档)。
  热力图下面那行显示「共打卡 N 天 · 最长连续 N 天」。只看不改。
- **任务** —— 打卡的地方。点一下记一次;右上「+ 新建」加自己的任务;
  「管理」进编辑模式,可以改任意一条,也可以删。
  **当天做完的会变暗,并自动沉到列表最下面**,组内保持原顺序(不会乱跳)。
- **今天** —— **今日主线** + **倒计时** + 今天的时间线 + **断了的** + 今日结算战报。
- **设置** —— 日历导出、备份导出/导入、清空、演示模式。

分页的理由:原来所有东西挤在一屏里往下滚,想看属性要先划过任务列表。
现在一页只做一件事。日历和备份属于「配置」,不该占今天页的位置。

### 今日主线

每天由 App 从没完成的任务里挑**一条**,放在今天页最上面,带「换一条 / 就做这个」。

挑选规则是 `没做的天数 × 2 + 经验 ÷ 10`,也就是**偏向"你躲得最久、但价值最高"的那条**。
当天选定后会记住(`S.focus`),不会因为你刷新而乱跳;做完一条会自动挑下一条。

这条卡片的目的是把"从 11 条里选一条"这个动作从你手里拿走——那个选择本身耗掉的执行力,
往往比执行还多。

### 倒计时

真实硬日期的天卡,可自己加(期末、重修考试、报名截止……)。新建时自带一个「四级」,
日期按 12 月的第三个周六算。

属性页 HUD 里那个数字也跟着**最近的**倒计时走,所以全 App 只有一处真相,不会两处打架。

### 断了的

列出**连续 N 天没做**的任务,按断的天数排序,最多 6 条,超过 5 天标红。

现在的「连击」是个总数,断的时候只知道"我断了",不知道断的是哪一条。
这条列表就是把悄悄停掉的东西每天摆回眼前。

> 判据是「距上次完成的天数 ≥ 2」。只差今天没做(昨天做过)不算断,否则每天的未完成项
> 都会涌进来,列表就没用了。

## 演示模式(给别人看,不污染自己的数据)

两种用法,先分清:

1. **朋友用自己的手机打开链接** —— 本来就是隔离的。数据存在各自浏览器的 localStorage 里,
   你什么都不用做。
2. **把手机递给朋友点几下** —— 先进入演示模式。

进入方式:设置页点「进入演示模式」,或在网址后面加 `?demo=1`。

演示模式做四件事:

- 用一份**造出来的假数据**:近 40 天、故意留了 5 天空档、今天已打卡 7 条 —— 所以看起来是"活的",不是空壳
- 存到**另一个键**(`liferpg.demo`),完全不碰 `liferpg.v1`
- **一点都不落盘**(`save()` 在演示模式下直接 return),朋友点什么都不会留下痕迹,退出即恢复
- 顶部挂一条黄色横幅写明"数据是假的",带「退出演示」;设置页的备份/导入/清空也会隐藏

假数据是**确定性**生成的,所以每次进演示模式看到的样子完全一样。

## 日历导出

任务里填了「时间」的,会导出成**每天重复**的日程(`.ics`)。

- 「分享到日历」走 iOS 分享面板;「导出 .ics」存到「文件」App,点它系统会问是否添加到日历。
- 每条任务的 UID 是固定的(`liferpg-<任务id>@life-rpg`),
  所以改了任务重新导入时,**多数日历会按 UID 覆盖而不是新增一条**。
- 这是**单向**的:App 是源头,日历只是收件箱。在日历里改了什么不会回到 App。

如果导入后发现重复了,说明你的日历不按 UID 去重。办法是导入时选一个专门的
「life-rpg」日历,以后要重来就把那个日历整个删掉再导一次。

## 本地改完怎么重新发布

```powershell
powershell -ExecutionPolicy Bypass -File _deploy.ps1
```

改完 `index.html` 后跑一次这个脚本,线上就更新了。手机上强制刷新一次即可。

`CACHE` 版本号由脚本**自动**改成当前时间戳,不用手动管。

原因:手机上的 Service Worker 只在 `sw.js` 字节变化时才会更新。如果只改了
`index.html` 而没动 `sw.js`,手机会一直从旧缓存里读页面,你看到的就是旧版 —— 这个坑踩过一次,
所以现在每次部署都强制换一次缓存名。

## 自检

```powershell
node _selftest.js
```

改了 `index.html` 的脚本后跑一次,会验证语法、等级曲线、连击、战报、持久化。

## 数据

数据存在手机浏览器的 localStorage 里,不上传任何服务器。

> **必须"添加到主屏"。** iOS 的 Safari 对普通网页标签有 7 天不访问就清除本地存储的策略,
> 而添加到主屏的独立应用不受这条限制。另外每周导出一次 json 备份,存到 D 盘。
