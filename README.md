# 战力面板 Life RPG

把每天的固定动作换成经验值。手机端 PWA:加到主屏即可离线使用。

线上地址:https://guangcat.github.io/life-rpg/

## 设计上的四条硬规则

1. **属性从成绩单长出来,不是通用四维。** 数学 / 英语 / 专业 / 毕业 / 体力 / 情报。
2. **经验绑在真事上。** "要考纲 / 往年题"给情报 +35,因为免听课最大的风险是不知道考什么。
3. **最小入口 8 分,不是 40 分。** "打开计划看一眼"存在的唯一目的是在不想学的那天保住连击。
4. **所有动作 ≤40 分钟。** 入口必须是一个动作,而不是一个判据。

## 四个页面

- **属性** —— 等级、经验条、六个属性、**热力图**(近 16 周,每格一天,按当天 XP 分五档)。
  热力图下面那行显示「共打卡 N 天 · 最长连续 N 天」。**点任意一个格子**会展开那天的明细
  (日期、几条记录、多少 XP、最后一条的时间),再点同一格收起。
  手机上 `title` 属性是不显示的,所以格子必须点得动。
- **任务** —— 打卡的地方。点一下记一次;右上「+ 新建」加自己的任务;
  「管理」进编辑模式,可以改任意一条,也可以删。
  **当天做完的会变暗,并自动沉到列表最下面**,组内保持原顺序(不会乱跳)。
- **今天** —— **今日主线** + **倒计时** + 今天的时间线 + **断了的** + 今日结算战报
  (可复制,也可直接走系统分享面板)。时间线每条右边有个 **✕**,点错了能撤销。
- **设置** —— 日历导出、备份导出/导入、清空、演示模式。

分页的理由:原来所有东西挤在一屏里往下滚,想看属性要先划过任务列表。
现在一页只做一件事。日历和备份属于「配置」,不该占今天页的位置。

### 今日主线

每天由 App 从没完成的任务里挑**一条**,放在今天页最上面,带「换一条 / 已经完成」。

挑选规则是 `没做的天数 × 2 + 经验 ÷ 10`,也就是**偏向"你躲得最久、但价值最高"的那条**。
当天选定后会记住(`S.focus`),不会因为你刷新而乱跳;做完一条会自动挑下一条。

「没做的天数」的基准是**这条任务自己的创建日**(`added`)或它上次完成的时间,**不是 App 的年龄**。
否则越晚添加的任务越吃亏:今天新加一条,会被算成"已经荒废了三个月",还会挤上今日主线。

这条卡片的目的是把"从 11 条里选一条"这个动作从你手里拿走——那个选择本身耗掉的执行力,
往往比执行还多。

### 倒计时

真实硬日期的天卡,可自己加(期末、重修考试、报名截止……)。新建时自带一个「四级」,
日期按 12 月的第三个周六算。

属性页 HUD 里那个数字也跟着**最近的**倒计时走,所以全 App 只有一处真相,不会两处打架。

### 断了的

列出**连续 N 天没做**的任务,按断的天数排序,最多 6 条,超过 5 天标红。

现在的「连击」是个总数,断的时候只知道"我断了",不知道断的是哪一条。
这条列表就是把悄悄停掉的东西每天摆回眼前。

> 判据是「距上次完成的天数 ≥ 2」。只差今天没做(昨天做过)不算断,否则每天的未完成项
> 都会涌进来,列表就没用了。

## 防连点与撤销

这两条是一对,不能只做一条。

**一天一条任务只能记一次。** 否则连点就能刷经验 —— 实测连点 10 次会把当天直接顶到热力图最亮档、
等级跳到 Lv 3,那等级和热力图就都不可信了。第二次点会提示「今天已经打过卡了」,不加分、不记录。

**点错了用「今天」页的 ✕ 撤销。** 撤销必须**同时回滚三处**:属性经验、当天 `days`、`log`;
当天记录数减到 0 时,把那一整天从 `days` 里删掉(连击才会跟着断)。漏一处,统计就长期偏掉。

## 完成音效

每次打卡(包括今天页「今日主线」的「已经完成」)都会响一声成就音。

- 默认音效是**现场合成**的:上行三音 E5 → B5 → E6,每个音叠三个泛音、指数衰减约 0.55 秒。
  **不需要任何音频文件**,离线也能响,也没有版权问题。
- 想换成自己的音效:把 `achievement.mp3`(或 `.m4a` / `.ogg`)放在和 `index.html`
  同一个目录,部署后会自动优先用它,合成音退化为兜底。
- 设置页有「完成音效:开 / 关」,随时可关。

> **iOS 注意:** 手机侧面的静音拨片会连网页音效一起静音,这是 Safari 的行为,不是 App 的问题。
> 听不到声音时,先检查拨片和媒体音量。

#### 音效怎么验证

```powershell
& $Chrome --headless=new --dump-dom --virtual-time-budget=60000 `
    --allow-file-access-from-files _mock\verify-sound.html
```

它用 `OfflineAudioContext` 把**同一段合成逻辑**真渲染成 1.2 秒波形,再统计峰值 / RMS / 包络。
只检查「没抛异常」是没用的 —— 整段全是静音也一样不抛异常。

## 演示模式(给别人看,不污染自己的数据)

两种用法,先分清:

1. **朋友用自己的手机打开链接** —— 本来就是隔离的。数据存在各自浏览器的 localStorage 里,
   你什么都不用做。
2. **把手机递给朋友点几下** —— 先进入演示模式。

进入方式有两种,区别很重要:

| 入口 | 网址 | 能否出来 |
|---|---|---|
| 演示模式 | `?demo=1` | 顶部横幅有「退出演示」链接 |
| 演示 · 锁住退出 | `?demo=1&lock=1` | **没有退出入口**(设置页的演示区块也隐藏了),关掉页面才能出来 |

**把手机递给别人时用「锁住退出」。** 它做了两件额外的事:

1. 横幅上的「退出演示」链接**不显示**,设置页的演示区块也一起隐藏 —— 朋友点不到回真实 App 的入口
2. 进入时用 `location.replace` 而不是 `location.href`,**把真实 App 那条历史记录顶掉** ——
   按返回键也回不到真实数据

装在主屏上的独立应用没有地址栏,所以锁住演示里,除了关掉页面,没有别的路能到真实 App。

演示模式做四件事:

- 用一份**造出来的假数据**:近 40 天、故意留了 5 天空档、今天已打卡 7 条 —— 所以看起来是"活的",不是空壳
- 存到**另一个键**(`liferpg.demo`),完全不碰 `liferpg.v1`
- **一点都不落盘**(`save()` 在演示模式下直接 return),朋友点什么都不会留下痕迹,退出即恢复
- 顶部挂一条黄色横幅写明"数据是假的",带「退出演示」;设置页的备份/导入/清空也会隐藏

假数据是**确定性**生成的,所以每次进演示模式看到的样子完全一样。

## 日历导出

任务里填了「时间」的,会导出成日程(`.ics`):没写星期的**每天重复**,
写了星期(`wd`,1=周一 … 7=周日)的只在每周那天重复,比如周六 09:00 的补课、周日 21:30 的复盘。

- 「分享到日历」走 iOS 分享面板;「导出 .ics」存到「文件」App,点它系统会问是否添加到日历。
- 每条任务的 UID 是固定的(`liferpg-<任务id>@life-rpg`),
  所以改了任务重新导入时,**多数日历会按 UID 覆盖而不是新增一条**。
- 这是**单向**的:App 是源头,日历只是收件箱。在日历里改了什么不会回到 App。

如果导入后发现重复了,说明你的日历不按 UID 去重。办法是导入时选一个专门的
「life-rpg」日历,以后要重来就把那个日历整个删掉再导一次。

## 同步到电脑(给考研那条流水线用)

打卡后 App 会把整份存档 PUT 到私有仓库 `guangcat/life-rpg-data` 的 `backup.json`,
电脑上的定时任务每天 22:40 拉一次,写进 `D:\考研\战力记录.md`。

### token 怎么来(只做一次)

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. Resource owner 选 `guangcat`;Repository access 选 **Only select repositories**,只勾 `life-rpg-data`
3. Repository permissions 里只开 **Contents: Read and write**,别的都不动
4. Expiration 选 90 天,到期重新生成、把旧的删掉
5. 复制生成的 token,粘到 App「设置 → 同步 → 粘贴 GitHub token」,离开输入框就会推一次

### 它存在哪

token 在 `localStorage['liferpg.sync']`,**不在存档对象 S 里**,所以「导出备份」拿到的
json 不含 token。App 只往 `api.github.com` 发请求,不经过任何第三方。

### 风险边界

这是个公开的静态页,能在这台设备上跑脚本的东西都读得到 localStorage。所以这个 token
只给单个私有仓库的 Contents 权限:就算泄露也读不到别的仓库,90 天自动过期。真出事就去
GitHub 删掉这个 token,App 里点「停用同步」。

### 它会失败的情况

手机访问不到 `api.github.com`(网络受限)、token 过期、权限给错。设置页那行状态会显示
「同步失败:读 401 / 写 403」之类,失败自动重试 3 次。电脑端拉取脚本是
`_pull_backup.ps1`,输出 `EMPTY` 表示仓库里还没有备份。

## 本地改完怎么重新发布

```powershell
powershell -ExecutionPolicy Bypass -File _deploy.ps1
```

改完 `index.html` 后跑一次这个脚本,线上就更新了。手机上强制刷新一次即可。

`CACHE` 版本号由脚本**自动**改成当前时间戳,不用手动管。

原因:手机上的 Service Worker 只在 `sw.js` 字节变化时才会更新。如果只改了
`index.html` 而没动 `sw.js`,手机会一直从旧缓存里读页面,你看到的就是旧版 —— 这个坑踩过一次,
所以现在每次部署都强制换一次缓存名。

## 自检

```powershell
node _selftest.js
```

改了 `index.html` 的脚本后跑一次,会验证语法、等级曲线、连击、战报、持久化。

## 数据

数据存在手机浏览器的 localStorage 里,不上传任何服务器。

> **必须"添加到主屏"。** iOS 的 Safari 对普通网页标签有 7 天不访问就清除本地存储的策略,
> 而添加到主屏的独立应用不受这条限制。另外每周导出一次 json 备份,存到 D 盘。

> **改了任务表要升版本号。** `DEFAULT_TASKS` 上面有个 `TASK_SET`,改表就 +1。
> 手机上已有存档在下次打开时会走一次 `upgrade()`:旧默认任务整批换成新的,
> 自己加的任务留下,**打卡历史(log / days / attr)一条不动**,原始 JSON 先存一份到 `liferpg.v1.bak`。
