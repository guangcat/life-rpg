# Life RPG 开发与维护

用户日常入口见上一级 README。这里集中存放 AI 协作、脚本、测试和预览材料。

- `_selftest.js`：`node AI辅助/_selftest.js`，只运行合成数据与模拟存储测试，不访问真实凭据或个人备份。
- `tests/`：日志迁移、统计、日切、休息、应用操作、日历、同步队列与 Service Worker 回归。
- `preview.cjs`：仅监听本机的预览服务，拒绝目录列表和备份文件访问。
- `browser-smoke.cjs`：隔离浏览器验证；命令为 `node AI辅助/browser-smoke.cjs <已安装的playwright模块路径>`。截图在 `预览/`，仅使用合成数据，不读取实际浏览器资料。
- `_deploy.ps1`：默认只跑自检并核对发布白名单；加 `-Publish` 才写入远端。一次提交更新全部文件，分支前进时停止。发布不包含 backup、截图、交接或私有数据。
- `_pull_backup.ps1`：从私有数据仓库拉取到上一级 `backup/`；执行会联网，先确认 GitHub CLI 与实际凭据。退出码：0 成功、2 缺失/空响应、3 请求/工具失败、4 内容无效。
- `_sync_to_kaoyan.ps1 -Out <输出路径>`：拉取后生成指定 Markdown，原样传递失败码。没有确认自动任务正在运行。
- `_make_icons.py`：用标准库重新生成上一级图标；不要无意覆盖已有图标。
- `_probe.js`、`_mock/`：历史单文件版本的诊断与设计样例，已不作为当前自检或界面事实；需要时先适配模块加载，不直接用于判断当前版本。

模块约定：`log` 是 XP 和活动的事实来源；`attr/days` 为兼容电脑工具而导出的派生缓存。`log.uid` 标识一次记录，`log.id` 继续表示任务，撤销按 uid。新记录使用所配置日切，旧记录的 d 保留。

真实设备、私有仓库与线上站点验证必须单独说明，离线样例通过不代表这些链路已验证。
